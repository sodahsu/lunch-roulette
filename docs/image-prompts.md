# Lunch Roulette image prompts

## Shared visual language

- mobile-first
- modern editorial sticker illustration
- soft 3D texture
- playful but sophisticated
- strong silhouette
- easy to read at phone size
- no text, no logo, no UI, no watermark
- consistent material, lighting and camera angle across all assets

## Avatar set

生成一組 8 個彼此明顯不同，但屬於同一視覺系統的匿名人物頭像。

每個角色都結合一種食物意象，例如：飯、麵、火鍋、咖哩、燒肉、雞蛋、蔬菜、甜點。

不要畫成具體真人，也不要有性別或年齡刻板印象。
每個角色使用簡單頭像構圖、清楚輪廓、不同姿勢與配件。
modern editorial sticker illustration、soft 3D texture、playful but sophisticated。
所有角色維持一致材質、光線、視角與視覺語言。
背景簡單，純色或透明感。
不要文字、數字、Logo、UI、浮水印。

## Persona card base prompt

製作一張「多人聚餐人格測驗」的手機收藏卡主視覺。
角色必須由食物意象與人格特徵融合而成，輪廓強烈、主角置中、留白清楚。
圖片必須在手機螢幕縮小後仍然一眼辨識。
modern editorial illustration、collectible personality card、soft 3D sticker texture、slightly absurd、playful but sophisticated。
不要任何文字、標題、Logo、UI 或浮水印。

### 和平飯友
一碗非常平靜的白飯擬人角色，周圍火鍋、拉麵、燒肉正在激烈競爭，角色只是微笑做出「都可以」的手勢。

### 逆風美食家
一隻時尚感的狼端著和大家完全不同的料理，背景所有箭頭往同方向，只有牠逆向前進。

### 挑食王
角色坐在簡潔王座前，大部分料理都被推開，只留下唯一一盤完美料理。

### 新店敢死隊
角色拿著骰子或探險旗，正走向一間神秘未知餐廳，其他角色在後方猶豫。

### CP 值守門員
角色像認真的分析師，一手計算機、一手筷子，比較價格、份量與食材。

### 五百公尺極限派
角色躺在沙發上，遠處有誘人的料理，中間距離被誇張描繪成遠征路線。

### 美食狂熱者
角色像熱血冒險者，穿越排隊、下雨、距離與高價障礙，朝最終美食前進。

### 真・都可以
稀有傳說感人格，角色漂浮在各種料理中間，所有食物和平共存，角色對每一道都完全接受。

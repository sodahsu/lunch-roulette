# 變更提案：分享卡圓角矩形相容性

## 原因與範圍
分享卡的外框、標籤與插圖裁切直接呼叫瀏覽器原生的圓角矩形繪製。Safari 16 以前沒有這個 API，iOS 16 以下的玩家按下匯出會得到錯誤訊息，拿不到人格卡，也拿不到團體成功率卡（兩張卡共用外框繪製）。

- 沒有原生圓角矩形繪製的瀏覽器，改用基本路徑指令畫出同樣的圓角矩形。
- 有原生支援時行為不變。
- 卡片版面、文案、尺寸與隱私欄位都不動。

## 非目標與待確認
- 不改分享卡版面、文案、配色與檔名。
- 不處理 iOS 16 以下其他尚未發現的相容性問題；實機驗證仍需人工，見 tasks。
- 不新增資料表、migration、RPC，也不改 Supabase、`vercel.json` 與 workflow。

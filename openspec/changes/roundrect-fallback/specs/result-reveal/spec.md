# 結果揭曉規格增量

## ADDED Requirements

### Requirement: 分享卡在不支援原生圓角矩形繪製的瀏覽器仍可匯出
系統 SHALL 在瀏覽器沒有原生圓角矩形繪製能力時，仍能產生人格卡與團體成功率卡，且卡面外觀與有原生支援的瀏覽器一致。

#### Scenario: 瀏覽器沒有原生圓角矩形繪製
- WHEN 玩家在沒有原生圓角矩形繪製的瀏覽器匯出人格卡或團體成功率卡
- THEN 系統仍產生 PNG 並走系統分享或下載
- AND 不得因為缺少該能力而顯示匯出錯誤
- AND 外框、標籤與插圖裁切的圓角形狀與有原生支援時相同

#### Scenario: 瀏覽器有原生圓角矩形繪製
- WHEN 玩家在有原生圓角矩形繪製的瀏覽器匯出分享卡
- THEN 系統沿用原生繪製，輸出與本變更之前相同

# 都可以？ (lunch-roulette) 🍱

> **多人即時飯局人格社交遊戲｜專治「隨便、都可以」的世紀大難題**  
> 嘴上每個人都說「超好約、吃什麼都可以」，結果一問去哪吃就全員裝死。  
> 12 題靈魂拷問，當場算出這團今晚到底約不約得成，並公開翻牌抓出誰才是隱形挑食王！

---

## 💡 為什麼做這個小工具？

每次朋友聚餐、同事午餐，群組最怕空氣突然安靜：
- 「等一下吃什麼？」
- 「隨便啊，我都 OK～」
- 「那吃義大利麵？」「呃……昨天才吃過。」
- 「那吃火鍋？」「今天有點熱耶……」
- 「那到底要吃什麼？」「我都可以啊，看你們～」

大家嘴上都說「都可以」，心裡卻各有堅持。  
《都可以？》是一場看似和平、實則殘酷又爆笑的**即時飯局社交實驗**：不用開冗長投票，只要兩分鐘做完 12 題二選一測驗，系統就會直接算出「這團今晚約成飯的機率（%）」，在眾目睽睽下翻出每個人的**飯局人格卡**、配對出**靈魂飯友**與**飲食天敵**，最後自動剔除所有人的地雷，端出一份「全員都能和平開飯」的安全名單！

## 🎮 遊戲怎麼玩？（只要 4 步驟）

```text
📱 1. 掃碼加入（支援主揪先開先玩）
   主揪在筆電／大螢幕一鍵開房，產生 6 碼房號與 QR Code，團員手機掃碼或輸房號秒進場。
   ✨ 支援「Solo Start／主揪先玩」：不用枯等別人，主揪自己就能先開答 12 題，朋友稍後掃碼加入也不會打斷進度。
       ↓
📝 2. 12 題二選一測驗 ＋ 忌口排除
   每房從 48 題庫中抽出同組 12 題快問快答（如排隊耐受度、步行極限、預算觀、是否真的好約），
   最後勾選「你不吃或吃不了的類別」（火鍋、燒烤、日式、重辣、素食等 12 類；沒勾代表都能接受）。
   交卷後可先在等待室偷看自己的「暫時人格」，鎖房前都能隨時回頭改答案。
       ↓
🎴 3. 兩段式刺激大揭曉（Two-Stage Reveal）
   【階段一：團體成功率】主揪按下「鎖定並揭曉」，大螢幕先對比「有多少人自稱超好約」，
   接著震撼公布這團實際「今晚約成飯成功率（%）」！
   【階段二：公開處刑 🎴】主揪再按一鍵，全場手機同步翻開專屬「飯局人格卡」，
   同時揭曉這場誰跟你最合拍（靈魂飯友）、誰跟你最常意見分歧（飲食天敵），
   大螢幕還會同步抓出全場吵最兇的「飲食內戰」與「歷史性共識」！
       ↓
🍜 4. 全體和平開飯推薦
   系統自動取全員忌口的交集，直接列出「大家都能吃」的餐點類別，挑一個就不會有人委屈；
   萬一這團連一個安全牌都沒有，系統也會誠實勸退：「沒有全員都能接受的類別，那就別聚餐了。」
```

### ✨ 還有這些讓人玩到停不下來的細節
- 🌟 **★ SSR 頂級稀有卡（金框保底機制）**：每局每人都有 3% 機率抽中閃亮金色外框的 SSR 稀有卡；若全場沒人中籤，系統還會從中保底送出 1 張，保證每局都有人歐氣爆發！
- 🤝 **靈魂飯友 vs 飲食天敵**：依 12 題作答相似度自動配對——誰跟你想法幾乎一模一樣、誰跟你一題不合就準備在餐桌上打架，翻牌瞬間全場立刻對號入座。

- ⚡ **即時多端同步 ＋ 儀式感音效**：主揪大螢幕與團員手機透過 Supabase Realtime 即時連動，搭配倒數與翻牌音效（右上角可隨時靜音）。
- 🎨 **Dark Editorial 黑色展覽感設計**：低調黑底（`#0b0b0c`）搭配 Electric Blue（`#4c6fff`）與 Acid Lime（`#c7ff3d`）螢光撞色，聚餐氣氛直接拉滿。
- 🛡️ **100% 匿名、免註冊**：採用 Supabase 匿名驗證（Anonymous Sign-In），打開網頁就能玩，不需填 Email 或綁定任何社群帳號。

## 🛠️ 本地開發與啟動

本專案使用 **Vue 3 + Vite + TypeScript + Supabase Realtime**，套件管理工具為 `pnpm`（`pnpm@10.30.3`）：

```bash
# 1. 啟用 corepack 並依照 lockfile 安裝相依套件
corepack enable
pnpm install --frozen-lockfile

# 2. 啟動本地開發伺服器
pnpm dev

# 3. 執行 TypeScript 型別檢查
pnpm typecheck

# 4. 執行單元測試（Vitest）
pnpm test:unit

# 5. 執行端對端測試（Playwright，會自動啟動 http://127.0.0.1:4173）
pnpm test:e2e

# 6. 建置正式版本（型別檢查 + Vite 打包）
pnpm build
```

> 💡 **快速預覽 UI 小技巧**：本地啟動 `pnpm dev` 後，可直接開啟 `/?demo=result`（或加上 `&persona=glutton&rare=1`、`&view=overview`）免連資料庫直接預覽人格卡與 10 人結果總覽版型。

### Supabase 匿名連線與環境變數設定
本專案前端已內建公開的預設 Supabase URL 與 `publishable key`（同 [`.env.example`](.env.example)），因此直接執行 `pnpm dev` 即可開房連線、不會白畫面。  
若要連接自己架設的 Supabase 專案（需啟用 **Anonymous Sign-Ins** 並套用 `supabase/migrations/` 下的資料表與 RLS 規則），可於根目錄建立 `.env.local`：

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

> ⚠️ **資安提醒**：前端環境變數（`VITE_*`）會直接打包進瀏覽器端程式碼，僅能填寫 `publishable key`（`sb_publishable_...` / anon key），**嚴禁**將 `service_role` 或任何 `secret key` 放進前端或 `.env.local` 中。

## 📂 專案結構導覽

- `src/App.vue`：主畫面與完整流程狀態機（開房大廳、主揪控制台、12 題答題、忌口排除、兩段式揭曉、個人結果與全員總覽）
- `src/domain/`：核心領域邏輯 — 48 題題庫與 10 種人格定義（`questions.ts`）、計分／配對／成功率與稀有卡演算法（`domain.ts`）、12 類忌口共識運算（`foods.ts`）、分享圖卡資料模型（`share-card.ts`）
- `src/lib/`：Supabase client（`supabase.ts`）、房間與 Realtime 即時同步服務（`session-service.ts`）、1080×1350 PNG 圖卡繪製（`share-card.ts`）、音效（`audio.ts`）與頭像對應（`avatars.ts`）
- `src/assets/`：10 種飯局人格插圖（`personas/*.webp`）與 10 款玩家頭像（`avatars/*.webp`）
- `src/components/`：共用元件（`PersonaGlyph.vue`）
- `supabase/migrations/`：PostgreSQL 資料表與 RLS 權限控管遷移檔
- `tests/`：Playwright 完整多端使用者情境測試（`CASE-01～26`）與資料庫 RLS smoke test
- `openspec/`：產品功能規格與各階段變更設計文件

## 🚀 分支與部署策略

- **分支政策**：日常開發與功能 PR 匯入 `dev` 分支，經過型別檢查、單元測試與 E2E 測試驗證後，再開 release PR 合併至 `main`。
- **線上部署**：Vercel 部署設定（[`vercel.json`](vercel.json)）僅綁定 `main` 生產分支；所有預覽分支與 `dev` 均略過建置，並加上 `noindex, nofollow` 標頭，確保正式環境穩定。
